Redesign page shells

Every page of the planner, rebuilt on the redesign CSS and structured so the planner’s own JavaScript still finds what it expects. Each file preserves its panel id, every JS mount-point id, and every onclick handler name from index.html.

These are shells, not finished pages. The planner renders its tables and stats into mount points with JavaScript, so opened standalone they look empty below the toolbar — that is correct. The <script> tags point at ../../js/planner.js and resolve once this folder sits inside the planner root.
